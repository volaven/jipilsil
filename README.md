# 집필실 · 쓰는 오늘, 완성의 내일로

한 문장씩, 이야기가 된다 ♡ — 초안부터 재독까지, 나만의 창작 메이트.
웹소설 작가를 위한 개인 집필 노트 (설치형 웹앱 · PWA). 서버 없이 기기 안(IndexedDB)에 저장하고, 원하면 내 구글 드라이브에 동기화해요.

- 실행: 내 Firebase Hosting 주소 `https://<내 프로젝트 ID>.web.app/` (`main`에 올리면 GitHub Actions가 자동 배포)
- 내 Firebase에 올리기 · 내 드라이브 연결 방법: [DRIVE_SETUP.md](DRIVE_SETUP.md)
- 내 값은 `config.js` 한 곳에만 넣어요: 드라이브 OAuth 클라이언트 ID(`DEFAULT_CLIENT_ID`), 직접 만든 APK 주소(`APK_URL`, 선택)
- 폰: 크롬에서 열고 ⋮ → **홈 화면에 추가 / 앱 설치**
- PC: 크롬·엣지 주소창의 설치 아이콘 ⊕ → 설치

## 로컬 AI 집필실

작품별로 Codex CLI·Claude Code·Gemini 웹·Grok 웹에서 의견을 모으고, 채택한 제안으로 다음 회차 초안을 작성할 수 있습니다. 검토한 초안은 기존 회차 저장·드라이브 동기화 흐름에 연결됩니다.

1. Node.js 24 이상을 설치하고 이 저장소를 내려받습니다.
2. Windows에서 `start-local.cmd`를 실행합니다. 또는 `npm ci` 후 `npm start`를 실행합니다.
3. `http://127.0.0.1:8765/`에서 **작품 → AI 집필실** 또는 **마이 → AI 연결 관리**를 엽니다.
4. Codex·Claude Code에 구독 계정으로 로그인합니다. Gemini·Grok은 `extension` 폴더의 Chrome 확장을 등록·연결하고 웹에서 로그인합니다.

GitHub Pages는 정적 집필 앱을 제공합니다. CLI 실행과 AI 웹 연결에는 이 PC에서 실행하는 로컬 서버가 필요합니다. 원고를 유지하려면 기존과 같은 브라우저·프로필·주소를 사용하세요. 웹사이트에서 쓰던 원고를 로컬로 옮길 때는 기존 내보내기·가져오기를 사용합니다.

- 전체 작품 참고, 긴 작품의 전회차 요약 캐시, AI별 담당 관점과 작품 지침 설정
- 제안 문단 선택, 추가 지시, 집필 AI·목표 분량 지정, 초안 검토와 회차 중복 추가 방지
- 작품별 요청·제안·초안 이력, JSON 백업·복원, 중단·부분 실패와 답변 직접 가져오기
- Gemini·Grok 연결은 웹 화면 자동화이며 공식 API 연결과 구분됩니다. 웹 화면·로그인·사용 한도에 따라 수동 조치가 필요할 수 있습니다.

상세 설정과 문제 해결은 [AI_SETUP.md](AI_SETUP.md)를 참고하세요. 기존 정적 서버 실행기는 `start-local-static.cmd`에 보존했습니다.

검증: `npm test`의 자동 검사 11개 통과, Codex 실제 제안 수집 → 초안 생성 → 회차 저장 확인. Claude·Gemini·Grok 실제 생성은 설치·로그인·확장 연결 후 별도 검증이 필요합니다.

## 기능
- 홈 / 작품 / 노트 / 보관함 / 마이 탭, 시작 화면
- 작품 → 회차 (순서 바꾸기, 이름, 회차 메모), 작품 전체 검색
- 방해 없는 에디터: 긴 붙여넣기, 글자수(공백 포함/제외)·단어수, 글자 크기, 낮/밤/세피아, 집중 모드, 고운바탕 서체
- 자동 저장(몇 초마다·창 벗어날 때), 오프라인 동작, 저장 상태 🟢🟡🔴
- 수정 기록: 몇 분마다 자동 + 직접 버전 저장, 비교(diff), 되돌리기
- 오늘의 집필(하루 목표), 연속 집필, 집필 타이머(뽀모도로), 북마크
- 작품별 **회차 목록표**(번호·제목·글자수·상태·한줄 메모·마지막 수정·드라이브 상태, 정렬, 합계)와 **인물·설정표**, CSV 내보내기
- **아이디어 사진함**: 사진 찍기·갤러리·붙여넣기, 설명·태그·작품/회차 연결, 기기에서 압축(긴 변 1600px)
- 음성 입력(받아쓰기, ko-KR), 낭독 듣기(목소리·속도·대사 다른 목소리), 음성 메모 녹음
- 내보내기 TXT / DOCX / 작품 전체 ZIP, TXT 가져오기(여러 개, 파일 이름에서 회차 번호, UTF-8/CP949)
- 구글 드라이브(drive.file 권한만): `집필실/<작품>/01화` 구글 문서, 목록표·인물·설정표 구글 시트, `음성메모/`, `아이디어 사진/` 폴더, 다른 기기 변경 받아오기, 충돌 시 선택(이 기기 / 드라이브 / 둘 다), 오프라인 대기열

## 개인정보
원고·사진은 기기에 먼저 저장되고, 드라이브 연결 시 **내 구글 드라이브**에 동기화돼요. AI 집필실을 실행하면 선택한 작품 자료가 해당 AI 서비스로 전송되고, 원고 스냅샷과 AI 이력은 로컬 데이터 폴더에도 저장돼요. 이 저장소에는 앱 코드만 있으며 원고·대화 이력·로그인 정보는 포함하지 않아요.
